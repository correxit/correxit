    Parameters¶

    Parameter Type Description
    rubric Rubric -
    outputs Outputs -
    id? string if the cell is not specified, all cells are scored. #### Notes If id is not provided, every cell in the rubric is scored. Cells that failed to execute (missing from outputs) will be marked as incorrect. All scores that already exist from previous scoring remain untouched as long as they exist in the rubric and have not been rescored.
