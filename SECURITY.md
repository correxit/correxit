# Security policy

## Supported versions

Correxit 2.x is the first supported public release line. The 1.x series was a
private, provisional development line and does not receive security updates.

| Version | Supported |
| ------- | --------- |
| 2.x     | Yes       |
| 1.x     | No        |

Correxit's security model, trust boundaries, and known limitations are
documented in [docs/security.md](docs/security.md).

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Once the repository is public, use
[GitHub's private vulnerability reporting](https://github.com/correxit/correxit/security/advisories/new).
Until that channel is available, email `correxit@darian.link` with the subject
`Correxit security report`.

Include the affected version, a concise description of the impact, steps to
reproduce the problem, and any suggested mitigation. Do not include real
student data, credentials, private keys, or live assignment material in a
report.

Maintainers will coordinate disclosure and remediation with the reporter. A
report is not eligible for a bounty unless a separate written arrangement says
otherwise.
